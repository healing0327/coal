# 印尼动力煤贸易决策可视化平台

基于 2026 年 3-4 月市场数据的实战分析工具

## 项目简介

这是一个专业的印尼动力煤贸易决策可视化平台，整合了CCI 价格指数、海运费、RKAB 审批进度、电厂库存等核心指标，为贸易商提供实时的利润测算、价格预测和策略建议。

## 功能特点

- 📊 **核心指标监控**：CCI3800/4700 FOB 价格、海运费、内外贸价差实时展示
- 💰 **贸易利润测算**：支持自定义参数，快速测算到岸成本和利润
- 📈 **价格预测与走势**：提供 4 月下旬和 5 月价格预测，包含敏感性分析
- 🎯 **贸易策略建议**：保守型和激进型两种方案，附带套利机会分析
- ⚠️ **风险预警**：出口税政策、中东局势、需求不及预期等风险评估
- ✅ **决策检查清单**：每日/每周/每月必查指标清单

## 本地部署

### 环境要求

- Python 3.8+
- pip 包管理器

## 核心指标说明

### 决策级指标（每日关注）
- **CCI3800/4700 FOB**：印尼动力煤离岸价，采购成本基准
- **海运费**：印尼至华南港运费，受油价和地缘政治影响
- **内外贸价差**：判断进口煤性价比的关键指标
- **电企招标价**：销售价格参考

### 预警级指标（每周关注）
- **RKAB 已批额度**：影响供应预期的核心政策指标
- **中国电厂库存可用天数**：17-18 天为正常，低于 12 天需补库
- **印度电厂库存可用天数**：19-20 天为安全水平

## 贸易策略速查

### 采购触发条件
- ✅ 内外贸价差顺挂≥20 元/吨
- ✅ CCI3800 FOB ≤ 56 美元/吨
- ✅ 海运费≤9 美元/吨
- ✅ 中国电厂库存可用天数≤15 天

### 风险触发条件
- ⚠️ 出口税税率>3%：重新测算成本
- ⚠️ 海运费>10.5 美元/吨：推迟发运
- ⚠️ CCI3800 FOB > 60 美元/吨：暂停采购
